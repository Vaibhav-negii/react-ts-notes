# GitHub Lookup

A simple app to search GitHub users and view their profile — built with React + TypeScript.

## Features
- Search any GitHub username
- Displays avatar, bio, followers, and public repo count
- Error handling for invalid usernames

## Tech Stack
React, TypeScript, GitHub REST API
